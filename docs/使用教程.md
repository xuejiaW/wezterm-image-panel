# WezTerm Image Panel 使用教程

这个工具把本地 Codex CLI 会话里的图片显示在 WezTerm 侧栏或独立窗口中。
你可以继续和 Codex 对话，同时浏览截图、暂停自动跟随，或回到最新图片。

交互式预览支持 **原生 Windows 和 macOS**，需要 Python 3.9+ 和 WezTerm。
Windows 已通过实际进程中的图片命令、翻页和侧栏回调测试；截图目视检查与实体快捷键
尚未验证。macOS 保留早期验证结果，Linux/WSL 尚未验证。具体见验证范围。
它是独立社区工具，不需要 OpenAI API Key。

## 安装

下载或克隆工程后，在普通终端中进入项目目录，执行：

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m wezterm_image_panel --version
```

后面的命令可以把 `wezterm-image-panel` 换成
`.\.venv\Scripts\python.exe -m wezterm_image_panel`。部分 Python 发行版会生成 `bin`
而不是 `Scripts`，请使用实际生成的解释器路径。

macOS：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
source .venv/bin/activate
wezterm-image-panel --version
```

这不会修改你的 WezTerm 配置。每个新终端可以重新激活环境，或直接使用
`.venv/bin/wezterm-image-panel`。修改源码后，重新执行 `pip install -e .` 更新安装。

## 先运行不含个人数据的演示

```sh
python examples/create_demo_session.py
wezterm-image-panel inspect --rollout .codex-local/demo/rollout-demo-session.jsonl
wezterm-image-panel open --rollout .codex-local/demo/rollout-demo-session.jsonl --standalone
```

演示由程序生成三张几何测试图，不读取真实 Codex 会话。输出放在被 Git 忽略的
`.codex-local/` 中。如果文件已经存在，生成器会拒绝覆盖；可以使用 `--output`
指定新的文件名。动态演示见 [demo.md](demo.md)。

## 查看自己的会话

在普通终端中运行以下命令，不要把它输入到 Codex 的聊天输入框：

```sh
wezterm-image-panel sessions --limit 10
```

每行显示会话 ID 和工作目录。同一个项目可能有多个会话，请确认具体会话，
不要把列表第一项当作当前会话。

把 `YOUR_SESSION_ID` 替换成你的会话 ID：

```sh
wezterm-image-panel open --session YOUR_SESSION_ID --standalone
```

在 WezTerm 内打开右侧预览：

```sh
wezterm-image-panel open --session YOUR_SESSION_ID
```

如果从另一个终端发起，先运行 `wezterm cli list`，找到 Codex 窗格的 ID，
再指定目标窗格。下面的 `123` 也需要替换：

```sh
wezterm-image-panel open --session YOUR_SESSION_ID --pane-id 123 --percent 40
```

如果无法通过 ID 定位，可以显式指定本机日志：

```sh
wezterm-image-panel open --rollout /path/to/session.jsonl --standalone
```

支持 `CODEX_HOME` 环境变量，也可以用 `--sessions-dir` 指定会话目录。

## 设置开关快捷键

[examples/wezterm.lua](../examples/wezterm.lua) 展示了 Windows 的 Ctrl + Shift + I
和 macOS 的 Command + Shift + I 绑定。
将其中的 `root` 改为自己的工程目录，将 `root` 指向已创建 `.venv` 的工程目录，
再把这条绑定合并到现有 WezTerm 配置。

点击本机 Codex 窗格后，按快捷键打开侧栏，再按一次关闭。多个会话无法唯一判断时，
会出现选择列表。远程 SSH 会话不能直接依靠本机进程识别。
如果终端标题只有项目名，即使只有一个候选会话，也需要手动选择，以免误认旧会话。

不要用示例配置覆盖自己的整个配置。工程不会自动安装快捷键，也不要求特定的
固定目录。示例默认使用标准 Python 的虚拟环境路径；如有不同，请修改 `python`。
`panel.action { root = root }` 会查找工程的虚拟环境，兼容 Windows 的 `Scripts` 和 `bin`。
如果使用其他环境，请传 `command = { "解释器完整路径", "-m", "wezterm_image_panel" }`。

## 操作

先点击预览窗格，使键盘焦点进入预览。

| 按键 | 行为 |
| --- | --- |
| 左箭头 / H / K | 上一张，暂停自动跟随 |
| 右箭头 / J | 下一张，暂停自动跟随 |
| 空格 / L | 切换跟随状态；恢复时跳到最新图片 |
| O | 用系统图片查看器打开当前缓存图 |
| Q | 关闭预览，保留 Codex 进程 |

`LIVE` 表示跟随最新图片，`PAUSED` 表示停留在当前图片。
切换到另一个 Codex 会话时，请关闭旧预览，再对新会话打开预览。

## 排查问题

```sh
wezterm-image-panel doctor
wezterm-image-panel inspect --session YOUR_SESSION_ID
```

- 一直等待图片：核对会话，以及图片是否实际写入本地日志。
- 没有自动跳转：检查是否处于 `PAUSED`，按空格恢复跟随。
- 分屏控制超时：先使用 `--standalone` 独立窗口。
- 自动识别失败：改用 `--rollout`。Codex 更新后，本地索引格式可能发生变化。
- 文字太小：放大预览窗格，或按 O 用系统查看器打开。

单张图片上限为 32 MiB，支持 PNG、JPEG、GIF 和 WebP；GIF 不保证动画播放。
只有远程 URL、纯文本路径或未写入本地日志的图片可能无法显示。

## 隐私和缓存

图片缓存默认位于 macOS 的 `~/Library/Caches/wezterm-image-panel`，
Windows 的 `%LOCALAPPDATA%\wezterm-image-panel`。可以用 `--cache-dir` 修改，
当前没有自动清理功能。

日志、诊断输出、截图和缓存都可能包含私人信息。公开反馈或录制演示时，
请使用合成演示数据，并把本地材料保存在被忽略的 `.codex-local/`。
更多说明见 [隐私边界](privacy.md) 和 [验证范围](validation.md)。

## 工程结构

根目录只放说明文件和工程配置。运行代码位于 `src/wezterm_image_panel/`，
测试位于 `tests/`，开发检查位于 `scripts/`，WezTerm 接入文件位于 `integrations/`。
请先安装，再通过 `wezterm-image-panel` 或 `python -m wezterm_image_panel` 运行；
不要直接执行内部的某个 Python 模块。

## 从旧 codex-image-panel 副本迁移（macOS）

如果报错仍显示 `codex-image-panel`，并指向根目录的 `session_detection.py`，
说明当前快捷键还在运行旧副本。新版维护在 GitHub 的 `wezterm-image-panel` 仓库中；
仅更新另一个目录，不会改变旧快捷键实际启动的程序。

首次迁移时，在普通 shell 中运行：

```sh
git clone https://github.com/xuejiaW/wezterm-image-panel.git ~/tools/wezterm-image-panel
cd ~/tools/wezterm-image-panel
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m wezterm_image_panel --version
```

如果新版仓库已经存在，请进入该仓库后运行 `git pull --ff-only`，再安装。
修复后台辅助进程识别的版本为 **0.4.2**。

将现有图片面板快捷键的 action 改为新版接入文件：

```lua
local root = wezterm.home_dir .. '/tools/wezterm-image-panel'
local panel = dofile(root .. '/integrations/wezterm.lua')
-- 放进现有 config.keys，替换旧图片面板绑定：
-- { key = 'I', mods = 'CMD|SHIFT', action = panel.action { root = root } }
```

重新加载 WezTerm 配置，关闭旧预览，再从 Codex 窗格按 Command + Shift + I。
出现多个会话候选时，仍需选择目标会话；后台 `app-server` 不作为交互会话候选。
